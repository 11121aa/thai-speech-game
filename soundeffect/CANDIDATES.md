## Adding one

1. Save the mp3 into `soundeffect/` with a name matching the others
   (`SaltShake.mp3`, `Sizzle.mp3`, …). Keep them short — these all load on
   game start, so a 5-second clip costs every player the download.
2. In that game's `preload()`:
   `this.load.audio('ck_salt', 'soundeffect/SaltShake.mp3');`
3. In `create()`:
   `this.sfxSalt = this.sound.add('ck_salt', { volume: 0.6 });`
4. Play it where it belongs — for the salt, in `shakeOnce()` in
   `js/game-cooking.js`, replacing the `sfxChop` call.
5. Bump the `?v=` on that game's `<script>` tag in `game.html`, or browsers
   keep the old file.
